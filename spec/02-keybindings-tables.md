# 02 (appendix) — Default binding tables

Reference commit: `6ed285c3ec7a1d228def4d4e7021c6ba269f620c`

Generated by `tools/gen_key_tables.py` from `data/keybindings.csv` (gdb dumps of the
unmodified reference executables) — do not edit by hand.  Requirements that
govern these tables are in `02-keybindings.md`.

Columns: **Key** = notation shown in help lines (UTF-8 locale); **Input (ENV-BASE)** = bytes
the key sends in tmux-256color; **Function** = rc function name(s) (C symbol); **Tag** =
help-line label in this context; **Profiles** = which dumped profiles contain the binding
(`all-default` = every default-build profile, `+tiny` = also every tiny profile); **Condition**
= build condition / runtime condition at registration; **Src** = `src/global.c` line.
Order within a context is the lookup order: the first matching row wins.
