# Naro credits

Project: [JLuethe/naro](https://github.com/JLuethe/naro).

Naro is a Rust port of GNU nano, based on GNU nano 9.3 at the reference
revision listed below. Naro is a separate project from GNU nano.

GNU nano, the Free Software Foundation, and GNU nano's contributors provided the
reference behavior, binding/help data, syntax definitions and translations used
by this project. The reference revision is
`6ed285c3ec7a1d228def4d4e7021c6ba269f620c`.

Naro uses ncursesw, glibc/POSIX interfaces, GNU gettext and libmagic for native
terminal, locale, regular-expression and file-identification services.

Development was assisted by OpenAI Codex.

Naro's project license and reused-file attributions are documented in
[LICENSE](LICENSE), [NOTICE](NOTICE), and the original asset headers.
